# Navegue Seguro

Site educativo sobre prevenção de golpes na internet, feito com HTML, CSS e JavaScript.

O objetivo é explicar, de forma simples, como reconhecer mensagens suspeitas, proteger contas e agir quando acontece uma fraude. O site também tem um quiz com situações do dia a dia.

## Tecnologias

- HTML semântico
- CSS responsivo
- JavaScript puro, sem bibliotecas externas

## Como acessar

## Privacidade

O site não tem cadastro, anúncios, cookies de rastreamento nem coleta de dados. As respostas do quiz são processadas no próprio navegador.

Projeto educativo, sem vínculo com as instituições citadas nas fontes.
